# Handwritten Digit Recognition Using CNN

## CodeAlpha Machine Learning Internship

### Project Description

This project recognizes handwritten digits from 0 to 9 using a Convolutional Neural Network (CNN).

The model is trained using the MNIST dataset, which contains thousands of handwritten digit images.

## Dataset

The MNIST dataset contains:

- 60,000 training images
- 10,000 testing images
- Image size: 28 × 28 pixels
- Digits: 0 to 9

## Technologies Used

- Python
- TensorFlow
- Keras
- NumPy
- Matplotlib

## Machine Learning Model

A Convolutional Neural Network (CNN) is used for handwritten digit recognition.

The model includes:

- Convolutional Layer
- MaxPooling Layer
- Flatten Layer
- Dense Layer
- Output Layer

## Project Features

- Loads the MNIST dataset
- Normalizes image pixel values
- Reshapes images for CNN
- Trains the CNN model
- Evaluates model accuracy
- Predicts handwritten digits
- Displays the predicted digit and actual digit

## How to Run

1. Install the required libraries:

pip install -r requirements.txt

2. Run the Python file:

python handwritten_recognition.py

## Output

The program displays:

- Training accuracy
- Testing accuracy
- Test loss
- Predicted digit
- Actual digit
- Image of the handwritten digit
