# Credit Scoring Model

## CodeAlpha Machine Learning Internship

### Project Description

This project predicts the creditworthiness of a customer using past financial information.

The model uses Logistic Regression to classify customers into:

- Good Credit
- Poor Credit

### Features Used

- Age
- Income
- Loan Amount
- Existing Loans

### Machine Learning Algorithm

Logistic Regression

### Evaluation Metrics

The model is evaluated using:

- Accuracy
- Precision
- Recall
- F1-Score
- ROC-AUC

### Technologies Used

- Python
- Pandas
- Scikit-learn
